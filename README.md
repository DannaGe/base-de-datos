# Bases de Datos

Diseño, normalización y consultas de bases de datos relacionales.
Trabajos de Fundamentos de Bases de Datos
Instituto Tecnológico de Jiquilpan – Ingeniería en Sistemas Computacionales

## Proyectos

### Boutique Casual
`Trabajo individual` · Microsoft Access

Base de datos relacional para una boutique, desarrollada por etapas:
- **Diseño:** esquema relacional, diccionario de datos y relaciones entre tablas.
- **Normalización:** corrección de redundancias hasta llegar a las formas normales.
- **Álgebra relacional:** diagrama relacional y ejercicios de proyección.
- **Consultas:** consultas con proyección y restricciones.

Carpeta: [`boutique-casual/`](boutique-casual)

`[Individual / En equipo]` · Microsoft Access · Excel

## Conceptos que apliqué
- Modelo entidad-relación y modelo relacional
- Llaves primarias y foráneas
- Normalización (1FN, 2FN y 3FN)
- Álgebra relacional: selección, proyección y combinaciones
- SQL: funciones de agregación (AVG, COUNT, SUM, MAX, MIN) y orden de las cláusulas

## Herramientas
Microsoft Access · SQL · Microsoft Excel · Modelo entidad-relación
